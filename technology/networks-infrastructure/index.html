SUBJECT AREA / 05 — CONNECTIVITY & INFRASTRUCTURE

The systems that
connect everything.

A network allows computers and devices to exchange information. Behind a simple web page is a chain of equipment, protocols, addressing, servers and infrastructure.

How devices find one another

LOCAL NETWORKS

Switches, wireless access points and routers connect devices.

IP & PORTS

Addresses identify endpoints; ports direct traffic to services.

DNS

Domain Name System translates names into network addresses.

PROTOCOLS

Ethernet, Wi-Fi, TCP, UDP, HTTP and TLS define communication.

SERVERS & CLOUD

Physical servers, virtual machines and storage provide services.

SECURITY

Firewalls, encryption, authentication and patching reduce risk.

The journey of a web request

  1. DNS resolves the domain name to an address.
  2. Packets travel through local Wi-Fi or Ethernet, a router and onward networks.
  3. The browser establishes a secure connection where HTTPS is used.
  4. An HTTP request reaches the server or application.
  5. The response returns and the browser assembles and renders the page.

The physical internet

Cloud services still run on physical computers. Data centres contain servers, storage, networking equipment, power systems and cooling. Fibre-optic cables carry traffic between cities and continents, while internet exchange points allow networks to exchange data efficiently.

FROM THE ORIGINAL ARCHIVE

Network fundamentals and infrastructure

A network connects devices

A local network links devices in a home, school or workplace. Ethernet cables and Wi-Fi provide common ways to connect. A router helps move traffic between networks, while a switch connects devices within many wired local networks.

Packets and protocols

Data sent across the internet is commonly divided into packets. Each packet carries information that helps it travel towards its destination. Protocols define how devices format, address, transmit and interpret data so equipment from different makers can communicate.

IP addresses, DNS and websites

IP addresses identify network interfaces for communication. The Domain Name System (DNS) helps translate human-readable domain names into the addresses needed by network software. When you visit a website, your device uses several protocols and services to locate the server and request the page.

The journey is not one direct cable

Packets may pass through multiple routers and networks. Routing systems choose paths based on network information and policy; different packets from one communication can sometimes take different routes. The receiving system reassembles the data and passes it to the appropriate application.
