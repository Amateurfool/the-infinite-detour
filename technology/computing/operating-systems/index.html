COMPUTING HISTORY / THE USER EXPERIENCE

From flashing cursor to desktop and beyond

An operating system is the layer that makes a computer usable: it manages hardware, files, programs and the interface between a person and a machine. Its history runs alongside the history of computer hardware — and often changes how the same machine feels.

Companion to the hardware history

Read this timeline alongside the British home computer hardware history. The periods deliberately line up, although different machines and systems overlapped for years.

Late 1970s — the machine boots straight into a language

Many early home computers did not have a separate, full-featured operating system in the modern sense. Switch on a machine and you might arrive at a BASIC prompt. The built-in language was both the user's starting point and a way to make the computer do something useful. Programs could be typed in, saved to cassette and loaded again later.

Early 1980s — ROM, BASIC and simple environments

The ZX81 and Spectrum offered a direct route into BASIC. The BBC Micro's built-in BBC BASIC was particularly capable and became a familiar learning environment in British schools and homes. These systems were tightly linked to their hardware: the machine's ROM, memory map and input/output facilities shaped what software could do.

At the same time, business PCs were developing command-line operating systems. MS-DOS used typed commands to manage files and launch programs. It was powerful, but users needed to understand commands and directory structures.

Late 1980s — graphical environments become part of home computing

The Amiga's Workbench and Atari ST's GEM-based desktop made windows, icons, menus and a mouse central to the experience. Acorn's RISC OS, introduced with the Archimedes family, offered a distinctive desktop with drag-and-drop interaction and a strong relationship between the desktop and applications.

On IBM-compatible PCs, graphical shells and Windows releases gradually made the command line less visible for everyday tasks, although DOS remained an important foundation for much of the period.

1990s — Windows becomes mainstream

Windows 3.x and then Windows 95 helped establish a familiar desktop metaphor: a desktop, windows, icons, menus, folders and a taskbar. The operating system increasingly managed hardware behind the scenes, while users expected to install applications, connect peripherals and work with files without knowing much about the underlying machine.

Other paths continued. Apple's Macintosh system developed its own interface tradition, while Linux emerged as a flexible Unix-like operating system used by enthusiasts, developers and organisations.

2000s — stability, networking and the modern desktop

Windows XP became a familiar home and office platform. Mac OS X brought a Unix foundation to Apple's desktop line, and Linux distributions became easier to install and use. Networking, user accounts, permissions, automatic updates and support for USB devices became ordinary parts of the operating-system experience.

2010s — the operating system moves into your pocket

Smartphones and tablets changed expectations. Touch interfaces, app stores, sensors, location services and power management became central. Desktop systems continued to evolve, but many people now used several operating systems every day without thinking about it: a phone, a work laptop, a home PC and a games console.

2020s — cloud accounts, security and specialist processors

Today's systems are shaped by security updates, encryption, cloud synchronisation, virtualisation and support for increasingly specialised hardware. Windows, macOS and Linux remain important on desktops, while Android and iOS dominate phones. Operating systems also manage GPUs, neural processing units and other accelerators as well as traditional CPUs.

Look at the interface, not just the logo

Notice how the desktop changes: from typed commands and simple prompts to windows, icons, menus, a taskbar and eventually touch-first interfaces. The interface is the part most users see, but underneath it the operating system is also managing memory, files, devices and running programs.

What does an operating system actually manage?

PROCESSES

Starts programs, schedules processor time and manages tasks running at once.

MEMORY

Allocates working memory and keeps applications from interfering with one another.

FILES

Organises information into files and folders and controls access to it.

DEVICES

Uses drivers and system services to communicate with screens, storage, printers and networks.

INTERFACE

Provides command lines, graphical desktops, touch controls and accessibility features.

SECURITY

Manages accounts, permissions, updates, encryption and system protections.

Hardware and software: two histories, one experience

A faster processor or larger memory capacity can make new software possible, but the operating system determines how those resources are presented and shared. The move from cassette-based BASIC environments to graphical desktops was not simply a change in appearance: it reflected more memory, better graphics, storage devices and new ways of organising programs.
