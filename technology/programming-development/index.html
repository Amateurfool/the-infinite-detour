SUBJECT AREA / 04 — CODE & CREATION

Giving computers
their instructions.

Programming describes tasks precisely enough for a computer to carry them out. It combines logic, problem-solving, languages, tools and testing.

Ideas shared by many languages

SEQUENCE

Instructions arranged in a meaningful order.

SELECTION

Conditions choose different paths through a program.

ITERATION

Loops repeat operations for as long as needed.

DATA

Variables, types and structures represent information.

FUNCTIONS

Reusable units package behaviour and return results.

DEBUGGING

Testing and inspection help locate errors.

Languages and tools

C and C++ offer low-level control; Python is widely used for scripting and data work; JavaScript powers interactive web pages; Java and C# are used across application and enterprise development. Editors, integrated development environments, build tools and version control help organise projects and collaboration.

The web stack

HTML describes page structure, CSS controls presentation and JavaScript adds behaviour in the browser. Servers handle requests and application logic; databases store information; APIs let systems communicate. A website is a collaboration between browser, network, server-side code and data.

FROM THE ORIGINAL ARCHIVE

Programming concepts and development notes

A program is a set of instructions

A program describes operations and decisions. Variables hold values, expressions calculate results, conditionals choose between paths and loops repeat work. Functions package useful steps so they can be reused and understood.

Languages and tools

Programming languages provide different ways to express instructions. Some are commonly used for websites, others for systems, data, automation, games or embedded devices. Editors, compilers, interpreters, debuggers and version-control tools support the process of building and maintaining software.

How a web page comes to life

HTML describes the structure and meaning of page content. CSS controls presentation and layout. JavaScript adds behaviour and interaction. The browser interprets these resources, builds a document structure, applies styles and runs scripts to create the page you use.

Learn by making small things

A useful first project is a page with a heading, a short paragraph and a button. Change its HTML, adjust the CSS, then use JavaScript to make the button respond. Small experiments make abstract ideas visible.
