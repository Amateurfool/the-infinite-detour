THE DIGITAL OBSERVATORY/OPERATING SYSTEMS

SUBJECT AREA / 02 — SYSTEM SOFTWARE

The environment
behind the interface.

An operating system is the layer that makes a computer manageable. It coordinates hardware, runs programs, organises files and gives people ways to interact with a machine.

The computer's traffic controller

PROCESSES

Starts programs and schedules processor time.

MEMORY

Allocates working memory and protects processes.

FILES

Organises information and controls access.

DEVICES

Drivers connect screens, storage, printers and networks.

INTERFACE

Command lines, graphical desktops, touch and accessibility.

SECURITY

Accounts, permissions, encryption and updates.

From prompt to desktop to touch

Early home computers often presented a BASIC prompt or simple command environment. Disk systems introduced richer file management. Graphical interfaces made windows, icons, menus and pointing devices familiar. Mobile systems later placed touch, sensors, app distribution and power management at the centre.

Different operating-system families

DOS and Windows shaped the PC lineage. Apple's Macintosh systems developed a distinct graphical tradition, with modern macOS built on a Unix foundation. Unix and Linux systems are widely used on servers, workstations and embedded devices. Android and iOS dominate mobile computing.

An operating system is not an application. Word processors, spreadsheets and image editors belong in Software & Applications ↗.

For the physical components an OS manages, visit Hardware & Computer History ↗.
