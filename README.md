# The Infinite Detour

A public personal website for interests, learning, ADHD reflections, creative projects, technology and journal entries.

**Live site:** https://amateurfool.github.io/the-infinite-detour/

## GitHub Pages project-site path

This repository is a GitHub Pages project site. All HTML navigation, stylesheet, script and favicon references use the `/the-infinite-detour/` base path so they resolve under the repository's published subdirectory.

## Publishing

The `.github/workflows/deploy.yml` workflow deploys the static files to GitHub Pages whenever changes are pushed to `main`.
