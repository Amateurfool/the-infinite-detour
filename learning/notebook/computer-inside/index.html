What actually happens inside a computer?

A computer can look like one machine, but it is really a team of specialised components working together. This guide follows the journey from pressing the power button to opening an application — and explains what the main parts are doing along the way.

The short answer

The power system starts the machine. Firmware checks and initialises hardware. The operating system loads into memory. When you run an application, the processor executes its instructions, RAM holds the data it is actively using, storage keeps files for the long term, and other components handle graphics, input, output and communication.

1. A computer is a system, not just a processor

The physical parts are called hardware. The instructions and programs that tell the hardware what to do are software. Neither is very useful on its own: software needs hardware to run, while hardware needs instructions to perform useful tasks.

The same basic ideas apply to desktop PCs, laptops, tablets, phones, games consoles and servers. Their components may be integrated into one compact chip or spread across separate boards, but the jobs still need to be done.

2. Meet the main components

CPU

The central processing unit executes program instructions and coordinates much of the computer's work.

RAM

Fast working memory holding the instructions and data currently needed by running programs.

Storage

An SSD or hard drive keeps the operating system, applications and files when the power is off.

Motherboard

The main circuit board connects components and provides pathways for data and power.

GPU

The graphics processing unit handles the calculations needed to create images and video; it may be integrated or separate.

Power & cooling

The power supply or battery delivers energy; heatsinks and fans help remove the heat produced.

3. How the parts fit together

The motherboard is the platform that lets the components communicate. It contains sockets, slots, connectors and electronic pathways. In modern machines, some of the functions once handled by separate chips are built into the processor itself.

4. The CPU: fetching and carrying out instructions

The CPU is not a tiny person thinking inside the computer. It is an electronic device designed to carry out instructions. A simplified description of its basic work is the fetch–decode–execute cycle:

  1. Fetch: retrieve the next instruction from memory.
  2. Decode: work out what the instruction is asking the processor to do.
  3. Execute: perform the operation — perhaps a calculation, a comparison or moving data.
  4. Repeat: continue with the next instruction, millions or billions of times each second depending on the processor and workload.

The CPU contains several specialised parts. An arithmetic logic unit (ALU) performs arithmetic and logical operations. Control circuitry directs the flow of instructions and data. Registers provide very small, very fast storage inside the processor.

Cores, clock speed and cache

A modern CPU often contains multiple cores, each capable of executing instructions. This can allow more than one stream of work to progress at once, although software must be able to make use of that parallelism. Clock speed describes the rate of a processor's clock cycles, but it is not a complete measure of performance: architecture, core count, cache, power limits and the work being done all matter.

Processors also use cache — small, fast memory close to or inside the CPU — to keep frequently needed data and instructions nearby. This reduces the need to fetch everything from slower main memory.

5. RAM: the computer's working space

Random access memory (RAM) holds data and instructions that the processor may need quickly. When you open a program, parts of it are loaded from storage into RAM. As you work, documents, browser tabs and other active data occupy memory too.

Ordinary system RAM is volatile: its contents are lost when power is removed. That is why saving a document matters. Saving writes the information to non-volatile storage so it remains available after shutdown.

Think of a workbench

RAM is like the clear space on a workbench: the larger and more available it is, the more material you can keep ready to hand. Storage is more like the filing cabinet where things remain when you leave the workshop. The analogy is imperfect, but it helps distinguish temporary working memory from long-term storage.

6. Storage: keeping things when the power is off

Storage holds the operating system, applications, photographs, music, documents and other files. Two familiar types are hard disk drives (HDDs) and solid-state drives (SSDs).

  • HDD: stores data magnetically on spinning platters, with moving mechanical parts. It can offer large capacity at a relatively low cost, but access involves physical movement.
  • SSD: stores data in flash memory and has no spinning platters. It is generally much faster and more responsive than a traditional HDD, particularly for random access, though performance varies by interface and model.

RAM and storage are not interchangeable. More storage gives you room for more files; more RAM gives running programs more working space. An SSD can make loading feel faster, but it does not replace the role of RAM.

7. Graphics, input and output

The GPU creates the images that appear on your screen. It can be integrated into the processor or provided by a separate graphics card. Dedicated GPUs are especially useful for demanding 3D graphics, video work and other highly parallel calculations.

Input devices — such as keyboards, mice, microphones and cameras — send information into the computer. Output devices — such as monitors, speakers and printers — present results. Network hardware lets the computer exchange data with other devices and services.

8. The operating system: the organiser

The operating system (OS) is the main layer of software that manages the computer's resources. Windows, macOS and Linux are desktop operating systems; Android and iOS are designed primarily for mobile devices.

The OS manages processes, allocates memory, organises files, coordinates access to devices and provides services that applications can use. Device drivers help the OS communicate with particular hardware. The operating system does not replace the CPU or other components — it coordinates how software uses them.

9. What happens when you press the power button?

  1. Power arrives. The power supply or battery provides the electrical power required by the components.
  2. Firmware starts. Firmware stored on the motherboard initialises essential hardware and performs startup checks. On modern PCs this is commonly UEFI firmware.
  3. A boot device is selected. The firmware locates a device containing a bootloader or operating-system startup environment.
  4. The operating system loads. Core parts of the OS are loaded from storage into RAM and begin managing the machine.
  5. You sign in and launch an application. The OS loads the program and its required data into memory, creates processes and gives them access to resources.
  6. The CPU gets to work. It executes instructions; RAM supplies active data; the GPU draws the interface; storage reads and writes files; input and output devices connect you to the result.

10. Follow a familiar example: opening a photograph

When you double-click a photograph, the operating system receives the input and asks the associated image application to open. The application is loaded from storage into RAM. The file's data is read from storage into memory. The CPU executes the application's instructions as it interprets the file, and the GPU/display system helps present the image on screen. If you edit the photograph and save it, the changed data is written back to storage.

Several components are involved in what feels like one simple action. That is the central idea of computer architecture: specialised parts cooperate to turn instructions and data into useful results.

Try this: investigate your own computer

  1. Find the processor model in Windows Settings or Task Manager.
  2. Check how much RAM is installed and how much is currently in use.
  3. Look at the storage section and identify whether your main drive is an SSD or HDD.
  4. Find out whether your graphics are integrated or provided by a separate GPU.
  5. Open Task Manager while launching a program and watch CPU, memory, disk and GPU activity.

You do not need to open the case or change any settings. The aim is simply to connect the names of the components to the behaviour you can observe.

The big idea

A computer works because specialised components cooperate. The CPU executes instructions, RAM keeps active information close, storage preserves files, the motherboard connects the hardware, the GPU handles graphics and the operating system coordinates access to it all.
