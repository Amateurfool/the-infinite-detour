Software & operating systems: instructions in action

Hardware provides the physical machinery; software gives it instructions. An operating system coordinates the machine so applications can use memory, processors, storage and connected devices without managing every detail themselves.

From an idea to a program

Software is a set of instructions and data that a computer can execute. Programs may be written in high-level languages, translated or interpreted by other software, and eventually carried out as operations the processor understands.

What an operating system does

An operating system manages processes, memory, files, devices, permissions and the user interface. It provides common services so applications can work with hardware through consistent interfaces rather than each application needing to control every component directly.

Applications, processes and files

An application is a program designed to perform a task. When it runs, the operating system creates and manages one or more processes, allocates resources and helps isolate work from other programs. Files and folders provide a familiar way to organise persistent information.

Drivers and the hardware boundary

Device drivers allow the operating system to communicate with particular hardware. A graphics card, printer, audio interface or network adapter may rely on a driver to expose its capabilities to the rest of the system.
