Networks & the internet: how devices find each other

The internet is a network of networks. It allows devices to exchange data using shared protocols, addressing systems and routing equipment — often across many independent networks before information reaches its destination.

A network connects devices

A local network links devices in a home, school or workplace. Ethernet cables and Wi-Fi provide common ways to connect. A router helps move traffic between networks, while a switch connects devices within many wired local networks.

Packets and protocols

Data sent across the internet is commonly divided into packets. Each packet carries information that helps it travel towards its destination. Protocols define how devices format, address, transmit and interpret data so equipment from different makers can communicate.

IP addresses, DNS and websites

IP addresses identify network interfaces for communication. The Domain Name System (DNS) helps translate human-readable domain names into the addresses needed by network software. When you visit a website, your device uses several protocols and services to locate the server and request the page.

The journey is not one direct cable

Packets may pass through multiple routers and networks. Routing systems choose paths based on network information and policy; different packets from one communication can sometimes take different routes. The receiving system reassembles the data and passes it to the appropriate application.
