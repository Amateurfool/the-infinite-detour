COMPUTING / PROFILE COLLECTION 01

Machines that made
their mark.

Meet some of the computers that shaped British home computing and the wider creative culture around it. These profiles will go beyond the timeline: what made each machine distinctive, how it worked, what it felt like to use and where its influence can still be seen.

THE LINE-UP

Five machines, five stories.

Selected to connect with the hardware and operating-system histories already in this section.

01 / COMPUTER PROFILENEXT STAGE

Sinclair ZX Spectrum

A low-cost colour computer that became a defining part of British bedroom programming and games culture.

1982 · 8-bit home computer
02 / COMPUTER PROFILENEXT STAGE

Acorn BBC Micro

A capable, expandable machine closely associated with the BBC Computer Literacy Project and education.

1981–82 · 8-bit home computer
03 / COMPUTER PROFILENEXT STAGE

Commodore Amiga

A multimedia pioneer whose graphics, sound and multitasking helped shape games and creative computing.

1985 onward · 16/32-bit family
04 / COMPUTER PROFILENEXT STAGE

Atari ST

A value-conscious graphical computer that became especially influential in music production.

1985 onward · 16-bit family
05 / COMPUTER PROFILENEXT STAGE

Acorn Archimedes

A distinctive British RISC computer that brought ARM architecture and RISC OS to desktop users.

1987 onward · ARM-based desktop
What each profile will explore

Release and context · processor, memory and graphics · distinctive hardware and peripherals · operating environment · notable software and games · strengths, limitations and legacy · sources and further reading.
